# Shavian UI Studio plugin

Created by **Shavian Music (@shavianofficial)**.

This plugin adds namespaced Claude Code skills and specialist agents for UI design work. It creates a project-local `design-brain/` but does not silently modify external services.

It ships with an embedded design-knowledge base (`reference/`), a parallel brainstorm, an auto mood board (Figma or local HTML), and a personal taste profile that learns your preferences over time.

Start with:

```text
/shavian-ui-studio:doctor
/shavian-ui-studio:bootstrap
```

Or jump straight from an idea to a screen:

```text
/shavian-ui-studio:vision <your idea>
```
