# UI rubric

| Criterion | Question | Minimum before approval |
|---|---|---|
| Hierarchy | Is the primary task obvious quickly? | 8 |
| Clarity | Can the user understand the screen without explanation? | 8 |
| Rhythm | Are spacing intervals deliberate and repeated? | 8 |
| Typography | Is the scale restrained and purposeful? | 8 |
| Component consistency | Are tokens and components reused correctly? | 8 |
| Premium feel | Does execution feel intentional rather than template-like? | 8 |
| Restraint | Does every visible element earn its place? | 8 |
| Accessibility | Are contrast, touch targets, keyboard states, and screen-reader implications considered? | 8 |
| Product fit | Does the screen match the brief and selected user job? | 8 |
| Anti-generic test | Could this be mistaken for an unrelated template? | 8 |
