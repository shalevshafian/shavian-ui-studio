# Privacy

Shavian UI Studio does not collect analytics, telemetry, credentials, or personal information.

Bundled scripts operate locally and make no network calls. They write only:

- inside the selected project root — the `design-brain/` scaffold, a marked section in `CLAUDE.md` (backed up first), and, when you build one, a local mood board under `design-brain/assets/moodboard/`;
- a single durable taste profile in your own Claude config directory at `~/.claude/shavian-ui-studio/taste-profile.md`. This is plain text, owned by you, never transmitted anywhere. Edit or delete it at any time.

Nothing is written outside these locations.

Optional third-party integrations are separate services with their own authentication and privacy terms:

- Figma MCP
- Mobbin MCP

Only connect services you trust. Do not upload confidential assets or private customer information unless you have permission to do so.
